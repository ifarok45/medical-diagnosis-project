# Medical Diagnosis Prediction System

## Overview

This project is a machine learning-based medical diagnosis system developed as part of the DEPI graduation project.

The system predicts possible medical conditions based on structured medical input through an interactive interface.

---

## Project Objectives

- Build an intelligent diagnostic support system
- Process and prepare medical datasets
- Train predictive models
- Provide an accessible user interface for interaction
